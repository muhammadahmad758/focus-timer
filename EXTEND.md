# Extend It — ideas for v1.1 and beyond

Pick any one; each teaches something new.

1. **Task labels** — a text box "What are you working on?" saved with
   each session, and a per-task totals view in the dashboard.
   (Teaches: extending a data format without breaking old files.)
2. **Daily goal ring** — set a daily target (e.g. 100 min) and show
   progress toward it on the main window.
   (Teaches: settings persistence — a `settings.json` next to the log.)
3. **Weekly review export** — one button that writes a `review.md`
   with the week's totals, best day, and streak.
   (Teaches: generating reports from the same stats functions.)
4. **System-tray / always-on-top mini mode** — a tiny floating timer
   that stays above other windows while you study.
   (Teaches: window attributes, a second view on the same core.)
5. **Sound choices** — pick the completion sound, or mute it.
   (Teaches: config plumbing from the GUI into the core app.)
6. **Charts inside the dashboard** — embed the matplotlib figures in
   the dashboard window with `FigureCanvasTkAgg` instead of PNG files.
   (Teaches: mixing matplotlib and tkinter in one window.)
